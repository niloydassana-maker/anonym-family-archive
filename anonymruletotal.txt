### 1. Common Setup (do once for both versions)

**Enable ADB**  
Settings → About phone → Software information → tap Build number 7 times → System management → Developer options → USB debugging.

**ADB Commands** (run in PowerShell):

```powershell
adb shell settings put secure location_mode 0
adb shell settings put secure location_providers_allowed ""
adb shell settings put global wifi_scan_always_enabled 0
adb shell settings put global ble_scan_always_enabled 0
adb shell settings put global wifi_on 0
adb shell settings put global bluetooth_on 0
adb shell settings put global nfc_on 0

adb shell pm list packages -3 | ForEach-Object {
    $pkg = $_.Replace("package:", "").Trim()
    adb shell pm revoke $pkg android.permission.ACCESS_FINE_LOCATION 2>$null
    adb shell pm revoke $pkg android.permission.ACCESS_COARSE_LOCATION 2>$null
    adb shell pm revoke $pkg android.permission.ACCESS_BACKGROUND_LOCATION 2>$null
}

adb shell appops set com.google.android.gms android:fine_location ignore
adb shell appops set com.google.android.gms android:coarse_location ignore
adb shell appops set com.google.android.gms android:monitor_location ignore
adb shell appops set com.google.android.gms android:monitor_high_power_location ignore
```

Optional stronger (can break some Google features):
```powershell
adb shell pm disable-user --user 0 com.google.android.gms.location
```

Reboot after running.

**Funtouch Manual Settings**
- Location → completely OFF (also disable Wi-Fi scanning, Bluetooth scanning, Google Location Accuracy)
- Google → Find My Device → OFF
- Permission manager → Location → Don’t allow for all non-essential apps
- iManager / Security → Auto-start → disable unnecessary apps
- Battery → restrict background activity for non-essential apps
- Network → Private DNS → hostname `dns.quad9.net`
- Install free Orbot → enable VPN mode → select only the apps you will use in bursts

Keep Location, Wi-Fi, Bluetooth and NFC off in the quick-settings panel by default.

**Weekly Audit**
```powershell
adb shell settings get secure location_mode
adb shell settings get secure location_providers_allowed
adb shell settings get global wifi_scan_always_enabled
adb shell settings get global ble_scan_always_enabled
```
